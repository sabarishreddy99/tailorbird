    What am I looking at?

    The agent works each queued URL through stages:
    fetch pulls the job description from any site.
    screen then decides one of:
    BUILD — clear fit, handed to the resume skill.
    NEEDS_REVIEW — a judgment call parked for you.
    HARD_DROP — a blocker (no sponsorship, clearance, dead posting).
    build runs the /resume-tailoring skill to write and verify the one-page resume, then sets the row resume_ready.

    Timestamped lines are live progress; the done: line summarizes the run. Click a past run in the list to read its summary.

    What Tailorbird does for you

    Tailorbird turns a job-posting link into a polished, one-page résumé tailored to that exact role, and does it for a whole queue of jobs on its own. Your job is to paste links and hit Run agent; it does the reading, screening, writing, and formatting, and keeps everything truthful.

    📥 Fetches any job posting

    Paste a URL from almost any careers site (Greenhouse, Ashby, Lever, Workday, Workable, Apple, Amazon, and more). Tailorbird pulls the full job description for you, no copy-pasting.

    📋 Or paste the description yourself

    Some postings can't be read automatically — sites that need a login, or a JD a recruiter emailed you. Hit text in the JD column (or + paste job description when adding) and paste it in. Tailorbird treats it exactly like a fetched posting, and the link is optional.

    🔎 Screens before it writes

    It checks each role for deal-breakers, visa sponsorship, security clearance, citizenship, or pay below your bar, and drops the dead ends automatically so you never spend effort on a role you can't take.

    ✍️ Tailors a résumé per role

    For each viable role it writes a one-page résumé (PDF + DOCX) matched to the job, starting from your best-fitting base and emphasizing what's relevant, without ever inventing experience.

    ⚠️ Flags the judgment calls

    When a role is borderline (an unusual level, a missing must-have, low fit), it marks it needs review with a reason instead of guessing, and you decide with one click: Build or Drop.

    ⚡ Runs on demand, or on a schedule

    Works through your whole queue one role at a time — reusing a single primed session so the skill loads once and every job stays cheap — on demand from the Run agent button or automatically on a daily schedule you control from the Schedule panel, even while your laptop sits idle.

    🎛 You pick the model

    Choose which model writes your résumés from the model dropdown in the agent bar, and optionally how hard it thinks. Opus is the default and the safest for quality; lighter models are there when you want speed or lower cost.

    ♻️ Tells you when to refresh

    The agent keeps one warm base session loaded with your facts, boundaries and style rules so each job stays cheap. If you edit those, or switch model, the dot next to Base session turns amber, because the warm copy is now out of date. One click on Refresh base session re-reads everything from scratch.

    📊 Tracks every application

    One table for the whole search: date, company, role, fit %, résumé PDF, and status. Open or copy any résumé's path in a click, filter, sort, search, and move roles through applied → interviewing → offer as you go.

    🪵 Shows its work

    The Logs tab streams live progress and past-run summaries, with the cost and time each run took, which base résumé it started from, and how many steps it needed, so nothing is a black box.

    🔒 Keeps your data yours

    Everything runs locally on your machine. Your résumés, knowledge base, and application history never leave your disk.

    How to use it

    1. On the Queue tab, paste one or more job URLs into the console and hit Add to queue.
    2. Click Run agent — it works through the queue one role at a time.
    3. Watch the Logs tab; results land back in the Queue table.
    4. Resolve any needs review rows (Build / Drop), then open the PDF for the ready ones and apply.
    5. Mark each row applied and beyond as you progress, that part stays yours.

    Status lifecycle

    queued → needs review → resume ready → applied → screen → interviewing → offer / rejected / dropped
    Tailorbird only ever sets dropped, needs review, and resume ready, everything past submission is yours.
